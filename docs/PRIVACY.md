# 隐私说明

Yang-gumi 采用“本地优先”设计：个人条目、评分、笔记、资源路径、访问令牌和图片文件夹路径默认只保存在运行它的电脑上。

可选的 Bangumi 账号连接只调用条目资料接口，用于补全 R18 动画、漫画、小说与游戏的封面和简介；不会读取或导入收藏，也不会向 Bangumi 写入数据。验证后的令牌在 Windows 上使用当前用户的 DPAPI 加密保存于 `data/`，不会进入数据库、导出、日志或公开仓库，断开连接时会删除该本地凭据。

## 会访问的外部服务

- Bangumi：搜索和读取公开条目、评分、排名、标签、简介与图片地址。
- Anime News Network、AniList、MyAnimeList、AniDB：季度条目来源核验与补充；不登录个人账户。
- 图片地址：在显示或建立缓存时下载对应公开封面。

外部服务可能按其隐私政策记录普通的网络请求信息。Yang-gumi 不需要 Bangumi OAuth，也不会写入用户的 Bangumi 账户。

## 不应提交的内容

以下目录和文件已被 `.gitignore` 排除：数据库、备份、导出、令牌、日志、本地封面、背景、季度海报、美图缓存、分享站运行时资源、隧道程序运行目录、`.env` 与 Streamlit secrets。提交前仍应运行 `git status`，确认没有使用 `git add -f` 强制加入私人内容。

只读分享运行时会在主人电脑上生成临时 HTTPS 链接、访问令牌和动态定位地址，并可能把它们写回本地 `启动只读分享.bat`，方便把单个 BAT 交给访客。公开提交前必须把 BAT 顶部的 `YANGGUMI_PUBLIC_URL` 与 `YANGGUMI_SHARE_LOCATOR` 清空；不要提交自动生成的访客 BAT、私钥、状态文件或隧道日志。

## 漏洞与敏感信息

发现安全问题或误提交的隐私数据时，请不要在公开 Issue 中粘贴令牌、数据库或私人路径；按照 [SECURITY.md](../SECURITY.md) 联系维护者并立即轮换相关令牌。
